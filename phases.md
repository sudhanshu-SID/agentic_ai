# Learning Phases: Agentic AI

This document outlines the breadth-first learning roadmap for Agentic AI.

## Phase 1: Python for AI Workflows
- **Main Outcome:** Comfortable building small backend/automation scripts.
- **Topics:** Functions, lists/dicts, JSON, File I/O, Exceptions, HTTP requests/REST APIs, Environment variables (.env), Virtual envs (pip/uv), async/await basics, Type hints (Pydantic).
- **Do NOT go deep yet:** Deep OOP, advanced internals, complex algorithms.

## Phase 2: LLM APIs
- **Main Outcome:** Can call models, manage prompts, structured output and errors.
- **Topics:** Chat/completions APIs, System/developer/user instructions, Tokens/context windows, Temperature, Structured outputs / JSON schemas, Streaming responses, Conversation state, Retries/timeouts, Rate limits, Cost basics, Prompt design.

## Phase 3: Tool Calling
- **Main Outcome:** Can give an LLM real capabilities through functions/APIs.
- **Topics:** Function/tool schemas, Arguments generated by model, Tool execution, Returning tool results, Validation/type safety, API/Database/Search tools, Tool permissions, Handling failed tools, Idempotency basics.

## Phase 4: Agent Loop
- **Main Outcome:** Can build the basic reason → act → observe loop yourself.
- **Topics:** Goal/task representation, LLM → tool call → result → LLM cycle, Exit conditions, Maximum iterations, State/history, Planning vs direct execution, Retries, Failure handling, Human approval checkpoints, Preventing infinite loops.

## Phase 5: RAG (Retrieval-Augmented Generation)
- **Main Outcome:** Can ground model responses in private/updated knowledge.
- **Topics:** Document parsing/chunking, Embeddings, Vector similarity search, Metadata filtering, Top-k retrieval, Context assembly, Grounded generation, Citations/source tracking, Chunk-size tradeoffs, Hybrid/keyword retrieval.

## Phase 6: MCP (Model Context Protocol)
- **Main Outcome:** Understand standardized model-to-tool/context connectivity.
- **Topics:** MCP client/server concept, Tools, Resources, Prompts, Tool discovery, Schemas and arguments, Transport basics, Permissions/security, Local vs remote servers.

## Phase 7: LangGraph
- **Main Outcome:** Can explicitly model stateful agent workflows.
- **Topics:** State, Nodes and edges, Conditional routing, Loops, Checkpoints/persistence, Human-in-the-loop, Subgraphs, Parallel execution, Retries, Streaming, Graph debugging/tracing.

## Phase 8: n8n
- **Main Outcome:** Can build practical AI + business automation workflows.
- **Topics:** Triggers/webhooks, Nodes and credentials, HTTP/API integrations, Data mapping, Conditional branches, AI Agent node, Sub-workflows, Error handling, Scheduling.

## Phase 9: Multi-Agent Orchestration
- **Main Outcome:** Can delegate, route, parallelize and coordinate agents.
- **Topics:** Supervisor/manager pattern, Handoffs, Specialist agents, Shared vs isolated context, Parallel tasks, Sequential pipelines, Agent routing, Conflict resolution, Result aggregation.

## Phase 10: Evaluation & Observability
- **Main Outcome:** Can measure and debug agent behavior.
- **Topics:** Traces, Logs, Tool-call history, Latency, Token/cost tracking, Success criteria, Golden test sets, Task-level evaluation, Groundedness, Regression tests.

## Phase 11: Production Deployment
- **Main Outcome:** Can turn a prototype into a reliable service.
- **Topics:** FastAPI, Docker basics, Postgres, Queues/background jobs, Auth, Secrets management, Rate limiting, Caching, Monitoring, CI/CD, Cost controls.
